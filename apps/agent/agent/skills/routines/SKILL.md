---
name: routines
description: Create or manage requested recurring or event-triggered assistance, including changes to future routine behavior.
---

Use wisp__manage_routine for requested recurring or event-triggered help. Read the catalog before choosing supported events/fields. Triggers are OR; filters are AND. multiple_of uses absolute values (even levels), not elapsed levels. Use supported events/intervals; evaluate other conditions with fresh reads when awakened.

Save a self-contained instruction with the user's goal, verified IDs, decision criteria and expected output: runs start fresh sessions. Explain the trigger, cooldown, online-only behavior and Routines sidebar. Read before editing; pause/resume/remove only on request.

Background runs are read-only and cannot edit routines. Handle a user's follow-up in a run normally; to change future behavior, update the saved routine and confirm it.
