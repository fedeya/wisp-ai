---
name: memory
description: Save, update or forget lasting player preferences and explicitly chosen character guides, goals or plans.
---

Store stable facts in the appropriate slot:

- preferences: this player's lasting play style and response preferences, shared across characters.
- character: explicitly chosen guides (with supplied URL/version), goals, build plans and user-reported guide checkpoints for this character.

When the user states, changes or retracts one of these facts, save/update/remove it using the matching memory tool. They need not say “remember”. Reuse the key for an updated fact. Asking about a guide is not choosing it. A checkpoint is reported history, not verified quest completion. Read live state before recommending next steps.

Do not store live level, location, money, points, spells, gear or quest completion, or infer commitments. New user statements override old memory. Users can view, edit and forget entries in Settings > Memory; recreate a forgotten entry only if they state it again.
