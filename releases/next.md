# What's new in Wisp

<!-- Add user-facing notes for the next stable release here. -->

## Improved

- Routines use less of your ChatGPT usage: they pause after you reach your usage limit instead of retrying every few minutes, and skip a check when nothing has changed since the last one had nothing to report.

## Fixed

- An empty orange dot no longer shows in the Wisp window header when everything is working.
- With Wisp set to Chinese, chat titles, your character and zone, and messages written with accents or ¿ (such as Spanish) now display correctly instead of showing gaps or empty boxes.
