# Clearer chat and smoother replies in WoW

## New

- Expand tool activity in the addon to see what Wisp looked up or did during a reply.
- Wisp now shows when it starts creating a panel, so you can follow its progress while the panel is being built.
- Added usage analytics to help improve Wisp, enabled by default in installed
  releases. It reports versions, activity and feature use using a random
  installation ID, without conversations, character names, tool arguments/results
  or credentials. Turn it off in desktop **Settings > Usage analytics**.

## Improved

- Replies appear progressively, with animated status text while Wisp is working.
- Chat titles appear sooner. Replies keep tool activity in order and display
  headings, lists, code blocks and tables more clearly.

## Fixed

- Styled text wraps correctly and long drafts scroll inside the chat composer.
- Macro previews show their actual icons.
- Updating the addon while WoW is open no longer risks leaving a partially written
  addon file.

After updating, use **Install / update addon** and reload WoW to load the matching addon.
