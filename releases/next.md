# What's new in Wisp

<!-- Add user-facing notes for the next stable release here. -->

## New

- Other addons can now add a "Review this with Wisp" button. It opens Wisp's quick question with their data attached, so you can see what is included before you press Enter. Nothing is ever sent without you. Addon authors can find the API at https://github.com/fedeya/wisp-ai/blob/main/docs/public-api.md.

## Fixed

- An empty orange dot no longer shows in the Wisp window header when everything is working.
- With Wisp set to Chinese, chat titles, your character and zone, and messages written with accents or ¿ (such as Spanish) now display correctly instead of showing gaps or empty boxes.
