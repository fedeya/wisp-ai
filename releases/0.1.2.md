# A clearer setup in WoW and smoother Windows updates

## New

- Windows updates show installation progress in a Wisp window. Wisp reopens when
  the update finishes. If installation stops with an error, the window shows
  what happened and the installation log.
- If setup is incomplete, open `/wisp` for instructions and a **Setup help**
  button. Once the addon is set up, the chat tells you when to open Wisp Desktop
  to connect.

## Improved

- New reply panels fade in as they appear in the WoW chat.
- Desktop and bridge logs include more detail to help troubleshoot startup,
  WoW detection, and slow replies.

## Fixed

- The classic Windows installer window no longer flashes during a Wisp update.

After updating, use **Install / update addon** in Wisp Desktop and reload WoW
to load the matching addon.
