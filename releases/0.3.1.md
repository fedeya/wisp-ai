# What's new in Wisp

## Improved

- Wisp answers gear and upgrade questions faster: it reads your equipped items' stats in one step and spends fewer steps re-checking items.
- The Wisp window shows "Connecting…" right after login and "Reconnecting…" while Wisp restarts or updates, instead of saying it is connected or asking you to open Wisp Desktop.

## Fixed

- After Wisp restarts or updates while WoW is open, the app shows the game as connected again within a minute, and update notices reach the game without you having to send a message first.
- If Wisp stops receiving your messages, the Wisp window now says so and asks you to type /reload instead of waiting forever. It also shows when an installed update needs a /reload.
- An empty orange dot no longer shows in the Wisp window header when everything is working.
- With Wisp set to Chinese, chat titles, your character and zone, and messages written with accents or ¿ (such as Spanish) now display correctly instead of showing gaps or empty boxes.
- When Wisp starts with Windows, installing an update now reopens the Wisp window instead of leaving it hidden in the tray.
